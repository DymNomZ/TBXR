## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Django 5.x + Django REST Framework |
| Frontend | React 18+ (via Vite)  + Tailwind CSS |
| Database | PostgreSQL |
| AI/ML | PyTorch + MobileNetV3 |
| Image Processing | Pillow, pydicom, opencv-python |
| Auth | Django Session Auth (MVP) |
